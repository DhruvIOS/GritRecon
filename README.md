# ⚡ GritRecon - UMBC Faculty Intelligence & Command Center

GritRecon is a modern web application and Chrome extension designed for UMBC students to analyze professor grade distributions, course difficulties, student reviews, and side-by-side professor comparisons directly on registration portals.

## 🚀 Features

- **Chrome Extension Overlay**: Highlight any instructor name to view real-time faculty intel popup.
- **Faculty Command Center**: Search and compare UMBC professors with official registrar grade distributions.
- **Side-by-Side Professor Comparison**: Compare two professors on metrics like GPA, Difficulty, Pass Rate, and Would Retake %.
- **Student Risk Matrix**: Automated risk flags (e.g., *Trap Class*, *High Grade Potential*, *Tough Grading*).
- **Student-Friendly UI**: High-contrast UMBC Black & Gold theme with clear metric tooltips.

## 🛠️ Getting Started

### 1. Web Application

Install dependencies and run the Next.js development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Loading the Chrome Extension

1. Open Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked**.
4. Select the `extension/` folder inside this project directory.
